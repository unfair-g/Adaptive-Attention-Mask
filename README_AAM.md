# Adaptive Attention Masking (AAM) 

本文档概括毕设论文《基于持续学习的道路场景语义分割方法》中的核心机制 **AAM（Adaptive Attention Masking，动态自适应注意力掩码）**，并与本仓库中的实现位置对应，便于复现与二次开发。

## 问题背景

在**在线类增量语义分割**设定下：数据流单次遍历、新数据往往只标注新类别，旧类像素常以背景或无标签形式出现，易产生**背景偏移**与**灾难性遗忘**。纯 Logits 蒸馏难以约束深层表征漂移；若再用**离散 0–1 掩码**截断注意力，会破坏 Transformer 依赖的全局长程依赖，在物体边界处造成表征割裂。部分掩码蒸馏又**过度依赖教师置信度**，在教师对新类尚未可靠时会把错误先验强加给学生。

## 方法总览

框架由三部分协同：

1. **EMA 双分支**：学生网络梯度更新，教师网络由学生权重指数滑动平均得到，作为稳定的历史表征锚点。  
2. **多级注意力蒸馏（MAD）**：在 SegFormer 编码器多个 Stage 上对齐师生**自注意力图**，采用**余弦相似度**度量方向一致性，而非强行 L2 数值对齐。  
3. **AAM（本文核心）**：在 **Query 维度**上生成 **0–1 之间的连续柔性权重**，与基掩码相乘后，对逐 Query 的余弦蒸馏项加权；用**表征漂移**与**认知不确定性**共同调节局部蒸馏强度，避免硬截断、缓解边界破坏。

## AAM 机制要点

### 基掩码（与教师置信度结合的空间有效性）

- 新类 GT 区域：不施加教师的注意力对齐（避免滞后教师误导新类）。  
- 背景区域：若教师 argmax 属于**已见旧类**且最大概率超过**松弛阈值**，则允许在该处进行蒸馏。  
- 回放样本：主要在有标注区域上做注意力蒸馏（论文叙述；实现以配置与损失逻辑为准）。

### 连续自适应权重（Query 维）

论文将两项在 Query 维对齐后融合（实现见 `src_attention/utils/attention_distillation.py` 及配置中的 STU/MAD 等相关开关）：

| 论文符号/称谓 | 含义 |
|---------------|------|
| **差分权重** | 师生在同一 Query 上的注意力向量差异（如余弦距离），刻画**时序上的注意力漂移**，漂移大处倾向加强蒸馏以拉回历史结构。 |
| **注意力熵权重** | 由学生注意力分布构造的**熵型不确定性**，高熵表示该处聚焦发散、认知模糊，赋予更大弹性以改善可塑性与边界过渡。 |

二者经**融合系数**（论文消融中典型量级约 **5.0**）合成后，与基掩码逐点相乘得到最终 Query 级权重，再乘到余弦注意力蒸馏损失上。

### 与「硬 0–1 掩码」的区别

- 硬掩码：区域外梯度硬切断，易损伤边界与全局上下文。  
- **AAM**：连续权重，保留长程依赖的**平滑过渡**，在旧类、模糊边界与可塑性之间自适应折中。
